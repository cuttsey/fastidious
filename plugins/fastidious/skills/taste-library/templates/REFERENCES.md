# References

Kept by taste-library. IDs are permanent: a retired ID is never reused.

Add a row for every site, image or object you want Fastidious to learn from. A reference needs both a Borrow and a Reject note; without them it is only a link. Put images, screenshots and scans in the `references/` folder beside this file, named by ID (`R-003.png`), and leave URL empty.

- **Teaches:** look, pattern, motion, type, structure or thinking.
- **Pattern:** hero, cards, cta, motion, typography, dark_mode, navigation and so on.
- **Fit:** direct (similar industry, register and audience) or aspirational.
- **Status:** active or retired.
